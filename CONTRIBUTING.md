# Contributing

New skills and fixes are welcome.

## Rules

1. **One skill per folder**, at `plugins/docs-skills/skills/<name>/`.
2. **Every skill has a `SKILL.md`** with `name` and `description` in its
   frontmatter. `name` matches the folder name.
3. **No private names.** No clients, colleagues, players, private repos
   or local paths. A skill must make sense to someone outside your
   project.
4. **Changes come as pull requests into `main`.** Nobody force-pushes
   `main`.
5. **Add a row to the skills table** in `README.md` for a new skill.
6. **Record where a skill came from.** If a skill or part of one comes
   from another repository, add its source, branch and commit to
   `PROVENANCE.md`.

## Upstream

A change that also fits a source repository in `PROVENANCE.md` can go
back there as a pull request. Update the skill's line in
`PROVENANCE.md` when it merges.
